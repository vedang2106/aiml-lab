Libraries for this experiment

Run on your PC

Install the common libraries in Command Prompt / PowerShell / terminal:

python -m pip install numpy pandas matplotlib scikit-learn

If python is not recognized on Windows, try py -m pip install numpy pandas matplotlib scikit-learn.

Package names: NumPy (import as numpy), pandas, Matplotlib, scikit-learn (import as sklearn).

Run in Google Colab
  • Open Google Colab and create a notebook.
  • Paste the same experiment code into a code cell.
  • Press Shift + Enter.
  • Plots appear below the cell.

Usually libraries are already installed. If imports fail, run this in a separate cell:

!pip install numpy pandas matplotlib scikit-learn
